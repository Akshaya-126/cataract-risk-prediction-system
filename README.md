# Cataract Risk Prediction System Using Machine Learning

## Overview

The Cataract Risk Prediction System is a machine learning-based healthcare application designed to assess an individual's risk of developing cataracts based on clinical and vision-related factors. The system enables users to enter relevant health information through a web interface and receive real-time risk predictions.

The project aims to support early awareness and encourage timely medical consultation by providing an accessible and user-friendly prediction platform.

---

## Features

- Cataract risk prediction using Machine Learning
- User-friendly web interface
- Real-time prediction results
- Data preprocessing and feature analysis
- Model training and evaluation
- Flask-based deployment
- Fast and lightweight prediction system
